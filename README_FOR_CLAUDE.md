# For a fresh Claude session
1. Read `docs/LESSONS.md` first (mistakes already made and how to avoid them), then the top of `PROGRESS.md`
   ("Waiting on the user") and its last entries. `ROADMAP.md` has the task list.
2. The original brief is `docs/BRIEF.txt`; `NOTES/STATE.md` and `NOTES/LOG.md` are the early project's notes (kept
   for history, not current).
3. Research notes on the game's code are local only (`build/decomp/notes_*.md`): read the one for your topic before
   testing or guessing about it.
4. Before any post: `docs/tests/RELEASE-CHECKLIST.md`.
