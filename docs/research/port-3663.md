## Tools (build/port3663, tools/native-port)

- `fmap.py`: the two exception tables (.pdata, 223,488 and 224,300 functions) aligned on runs of equal sizes (4 in a
  row, unique in both, increasing), gaps by size again (difflib) and by position: 215,383 pairs. `addr(old)` places an
  address in its paired function: the same masked instructions at the same offset ("same"), found once elsewhere
  ("moved"), the same mnemonics with other numbers ("same~" / "moved~"), the k-th call to the same function ("call"),
  between functions by both neighbours ("gap"). `target(fn)` / `callee(fn)`: a rewritten or moved function through what
  its callers call now. `data(g)`: a global through the code that addresses it.
- `p63.py scan | scan2 | judge | apply | heads | inline` for `native` and `layer`; hand decisions in `p63_hand.py`.
- `op63.py`: message numbers by name, classed (named / const / syntax rewritten; time / weak / review listed);
  `op63_hand.py` FORCE. Applied to both src trees and both test trees.
- `pins63.py` (build stamps, protection range and name, call sites INSIDE the protection by callee and order),
  `getters63.py` (the rewritten getters: `game::info_row`), `fields63.py` (structure fields).
- `structdiff.py` (which displacements moved in the functions a file touches), `stackdiff.py` (frames, stack slots,
  registers), `midsites.py` (the instructions around every mid-function address, old | new, clean or not),
  `look.py`, `troc63.py`.
