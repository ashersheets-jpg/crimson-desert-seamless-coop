# Credits

Crimson Desert Seamless Co-op+ is built on the work of others. Thank you.

## Code we build on (GPL-3.0)
- **ByJunter**: cdmp, Crimson Desert Multiplayer, the original co-op mod and its research on the game's internal
  client/server messages. https://github.com/ByJunter/CrimsonDesertMultiplayer, https://www.nexusmods.com/crimsondesert/mods/3677
- **ByJunter**: Crimson Desert Multiplayer, native server: the shared-world base our playtest builds run on. Its
  source with our changes is in `native-base/` (GPL-3.0, his licence file kept).
  https://github.com/ByJunter/CrimsonDesertMultiplayer-NativeServer
- **nouzert1** ("CD Coop Port"): cd-coop-3446, the port of cdmp to game build 1.0.0.3446. https://github.com/nouzert1/cd-coop-3446
